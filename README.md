# Quiet Notes · 일코 모드

SillyTavern을 메모 앱이나 전자책처럼 보이게 바꾸는 확장입니다. 지금 쓰는 UI 테마 위에 켜고 끄며, 끄면 원래 화면으로 그대로 돌아갑니다. 태번 헬퍼나 다른 확장이 필요하지 않습니다.

## 설치

실리 → 확장 → 확장 설치에 다음 주소를 넣고 새로고침합니다.

```
https://github.com/zxvniqi/quiet-notes
```

## 사용법

- **켜고 끄기**: 입력창의 마법봉 메뉴 → **Quiet Notes** → 설정창 맨 위 스위치. 단축키는 `Ctrl+Shift+M`입니다.
- **상단바·입력 바**: 채팅 위아래의 얇은 선을 누르거나 끌어서 열고 접습니다.
- **설정**: 마법봉 메뉴의 Quiet Notes, 또는 확장 설정의 Quiet Notes에서 엽니다. 설정은 이 기기의 브라우저에만 저장됩니다.

## 두 가지 모드

- **일반(메모)**: 흰색·회색·어두운 색 메모 화면. 본문 글꼴과 크기는 테마(및 폰트 매니저)를 따르고, 원하면 직접 정합니다.
- **전자책**: 종이 색(미색·흰색·베이지·회색·야간) 위에 본문만 책처럼 보여 줍니다. 상단에는 ‹(책장) · ☰(목차) · Aa(설정)만 남습니다.

## 설정

- **공통**: 전자책 모드, 프로필 사진·본문 이미지·임베드 패널·대화 이름·메시지 정보 가리기, UI 글자 크기, 알림 위치
- **일반 / 전자책**: 색 또는 종이, 본문 글꼴·크기·줄 간격·문단 간격, 구분선, 메시지 버튼(··· 메뉴로 접기, ··· 메뉴에 넣을 버튼 고르기). 전자책은 들여쓰기·좌우 여백·정렬도 고릅니다.
- **기타**: 탭 제목, 이름 바꾸기, 꾸미기 기본값

## 테마와 함께 쓰기

- 상단바, Chat Top Bar, 입력 바, 메시지 틀은 어떤 테마에서도 같은 모양으로 보입니다. 테마의 크기와 위치는 그대로 두고, 배경 그림·광택·장식만 걷어 냅니다.
- 메시지 정보(번호·시간·토큰), 이름 줄 표시, 버튼 크기는 테마를 따릅니다.
- 어두운 색(일반 다크·전자책 야간)에서는 서랍·팝업·메뉴도 어둡게 맞춰 글자와 아이콘이 보이게 합니다.
- 알림은 작은 알약 모양으로 바뀝니다. 내용은 그대로입니다.

대화 내용, 설정 파일, 테마 파일, QR 명령은 바꾸지 않습니다. 외부 통신이나 수집을 하지 않습니다.

## 최초 로딩을 완전히 대체하기

브라우저 확장만으로는 로딩 화면을 바꾸지 않습니다. 첫 화면부터 문서 로딩만 보이게 하려면 실리를 실행하는 서버에서 다음 일회성 설정이 필요합니다.

### 터묵스에서 한 줄로 적용

실리가 실행되는 터묵스에서 다음을 그대로 복사합니다. 설치 경로를 입력할 필요가 없습니다. 현재 위치가 실리 폴더 안이면 그 설치를 사용하고, 아니면 홈 폴더에서 자동 검색합니다. 여러 개면 번호를 선택합니다.

```sh
curl -fL "https://raw.githubusercontent.com/zxvniqi/quiet-notes/main/startup-setup.cjs?v=5" -o "$HOME/quiet-notes-startup.cjs" && node "$HOME/quiet-notes-startup.cjs"
```

Node.js는 실리 실행에 사용하던 것을 사용합니다. curl 명령이 없다면 먼저 `pkg install curl`을 실행하세요. 파일 하나에 필요한 CSS가 포함되어 있어, Quiet Notes 확장이 설치되어 있지 않아도 로딩 화면 교체만 따로 쓸 수 있습니다.

되돌리기:

```sh
node "$HOME/quiet-notes-startup.cjs" --remove
```

자동 검색은 홈 폴더 아래 6단계까지 확인하며, node_modules·data·캐시·연결된 공용 저장소는 건너뜁니다. 홈 밖의 설치를 쓰는 경우 실리 폴더 안에서 위 명령을 실행하면 경로 입력 없이 적용할 수 있습니다. 되돌리기는 적용 흔적이 있는 설치를 우선 찾습니다. 여러 설치에 적용했다면 번호로 선택한 설치만 변경합니다.

### Windows 등 다른 서버

이 저장소의 `startup-setup.cjs`를 내려받은 뒤 실행합니다. 경로는 실제 실리 설치 폴더로 바꿉니다.

```
node startup-setup.cjs --root "D:\SillyTavern"
```

현재 버전은 `config.yaml`의 `dataRoot`를 읽어 데이터 폴더의 `_css/user.css`에 시작용 CSS를 직접 넣습니다. 구버전만 `public/css/user.css`를 사용합니다. 이전 설치 도구가 public 경로에 넣은 규칙은 자동으로 정리합니다. 별도 CSS 요청을 기다리지 않고 첫 로딩부터 적용됩니다. 기존 user.css 내용은 보존하며, 최초 변경 전 `.quiet-notes-backup` 백업을 남깁니다. 여러 번 실행해도 중복되지 않습니다. 테마 파일이나 실리 코어 코드는 수정하지 않습니다.

실리 화면을 새로고침해 확인하세요. 기존 설치자도 위 명령을 다시 실행하면 다음 로딩에까지 나타나던 문서 아이콘이 첫 시작 화면으로만 제한됩니다. 이 설정은 서버의 모든 사용자에게 첫 시작 로딩 화면을 적용하며, 일코 OFF 상태에서도 동일합니다. 앱 설치 아이콘이나 HTML의 초기 탭 제목을 바꾸지는 않습니다.

되돌리기:

```
node startup-setup.cjs --root "D:\SillyTavern" --remove
```

서버에서 실행하기 어려우면 `startup.css` 내용을 실제로 제공되는 사용자 CSS 끝에 직접 덧붙여도 됩니다. 최신 기본 경로는 `data/_css/user.css`입니다. 기존 내용은 지우지 마세요.

## 끄기와 제거

끄면 화면이 켜기 전 상태로 돌아가고 남는 흔적이 없습니다. 제거하려면 확장 관리에서 제거한 뒤 새로고침하세요. 시작용 CSS를 적용했다면 위의 되돌리기를 먼저 실행하세요.

로딩 팝업과 아이콘 호환 구조는 [Blue Lemonade 3.7.9](https://github.com/kgangkgang/blue-lemonade)를 참고했습니다. 해당 확장의 코드를 복사하거나 설정을 변경하지 않습니다.
